# QuizApp 

Una app de trivia interactiva para iPhone desarrollada con SwiftUI.

## Descripción

QuizApp es una aplicación de preguntas y respuestas con diseño moderno, animaciones fluidas y una experiencia de usuario intuitiva. Desarrollada como primer proyecto iOS bajo la marca **iappting**.

## Características

- Pantalla de inicio animada
- Preguntas con imagen de referencia
- Temporizador de 15 segundos por pregunta
- Sistema de puntaje
- Animaciones en botones y resultados
- Feedback visual inmediato (correcto / incorrecto)
- Diseño moderno en tonos naranja

## Tecnologías

- Swift
- SwiftUI
- AVKit
- Xcode 16
- iOS 17+

## Instalación

1. Clona el repositorio
```bash
   git clone https://github.com/ValadezRicardo/QuizApp.git
```
2. Abre `QuizApp.xcodeproj` en Xcode
3. Selecciona un simulador iPhone
4. Presiona `Cmd + R`
